# 面试边注体验优化计划

更新：2026-09-09

目标：让用户打开后快速找到题、连续阅读、低成本练习；等待 AI 或切换题库时始终知道发生了什么。保留 React + TypeScript、SQLite、ECS 单写节点和游客可用边界，不为视觉改版引入新的运行时依赖。

## 当前落地情况

- P0 首批已上线（`f66dfc3`）：移除全局装饰字体 preload、补题库层级、懒加载骨架和错误播报。未测得首屏提速百分比，3秒/CLS目标仍待实测。
- P1 本批代码：全站搜索查服务端正文，显示总数/题库/命中片段并按24条分页；250ms防抖，取消旧查询；服务不可用时明确提示本地匹配范围。手机顶栏提供全站搜索按钮。
- AI 本批代码：修复切题草稿串写和过期请求回写；区分连接、等待首段、生成；错误紧邻输入框；向上阅读时暂停跟随新输出，可回到最新回答；流式增量不再逐次读写草稿存储。
- AI 故障体验补丁：失败响应保留结构化错误代码；AI 用量记录使用具体失败码；前端区分繁忙、限流、超时、配置、鉴权和主备均失败，并明确题目阅读仍可继续。

- 尚未完成：学习同步状态、后台密度、AI预算预占、分享图资源、内容精修，以及移动4G/CLS和完整桌面流程验收。上面几批不代表P0/P1全部完成。

## 体验基线

- 内容优先、克制的 Swiss / 编辑风格；正文比装饰重要，减少卡片、渐变和常驻工具。
- 所有可操作控件都有明确名称、至少 44px 点击区域、可见焦点、键盘路径和等待反馈。
- 桌面只保留一套全局导航、一套题内目录和一个上下文工作区；移动端抽屉互斥。
- 首屏只加载必要字体和题库索引，非首屏资源懒加载；目标 CLS < 0.1，移动 4G 首屏可交互 < 3 秒。
- 首屏先给结论、为什么、怎么用；长解释、代码、图解和来源按需展开。

## P0：打开后就好用

### 首屏与加载

1. 清爽主题只保留 Noto Sans SC 和 IBM Plex Mono；装饰字体改为用户主动选择后加载，移除 HTML 装饰字体 preload。
2. 首页只请求题库索引；正文、图片、图解和 AI 面板按进入时机加载。
3. 为题库卡片、阅读正文、AI 面板和反馈列表保留稳定尺寸；长等待显示 skeleton 或 `aria-busy`。
4. 分享图转换为 WebP，保留 PNG 降级资源并检查缓存头。

验收：Chrome 移动 4G 模拟下首屏可交互 < 3 秒；无明显跳动；首屏不请求未选择的装饰字体。

### 阅读主流程

1. 题库中心只承担“选方向、选题库、继续学习”；移除重复的设置、批注和搜索入口。
2. 顶栏统一为：题库/章节/Q号、全站搜索、收藏、上一题、下一题、阅读版式。
3. 题内目录只负责定位正文，统一为“速答、原理、实战、避坑、来源、追问”；不存在的段落不显示。
4. 右侧只保留一个“批注 / AI”上下文工作区；移动端不能同时打开题库和上下文抽屉。
5. 进入长题目时恢复上次位置并显示“本题阅读进度”；切题时保留未发送草稿并提示。

验收：游客从首页到第一题不超过两次点击；桌面和移动端都能完成“选题 → 阅读 → 下一题 → AI/批注”；Tab 顺序与视觉顺序一致。

## P1：提高连续学习效率

### 搜索与导航

- 全站搜索与当前题库筛选使用不同文案、快捷键和空状态。
- 结果展示题库、章节、方向、难度、频率和命中片段；支持继续加载和清除筛选。
- 无结果时建议换关键词、查看相邻题或回到当前题库。
- 结果超过 100 项时采用窗口化或分页，避免一次渲染全部节点。

### AI 反馈

- 空状态只显示“讲简单点、画流程、举例子、模拟追问”四个动作。
- 流式等待显示连接中、生成中、已停止、失败可重试；错误信息靠近输入框，不只显示 Toast。
- 回复默认先结论后展开；引用“原理/代码/避坑”时可回到对应段落。
- 评分固定显示原句证据、扣分原因、更准确说法、下一步练习。
- 预占额度时计入系统提示词、题目正文和历史消息，避免并发下低估全局预算；管理员显示估算与供应商 usage 差异。

### 学习状态

- “未开始 / 学习中”作为自动状态，“需复习 / 已掌握”作为明确主动作。
- 复习队列展示原因、到期时间和预计用时；完成一道题后直接给下一步。
- 同步失败时显示“已保存在本机，等待同步”，不让用户猜测是否丢失。

验收：连续完成 5 道题无需打开设置或返回首页；断网、恢复、切换账号时不串号、不丢草稿。

## P1：降低后台和运维复杂度

- 后台首页只展示待处理反馈、待审核内容、邀请状态、最近备份和 AI 用量；详细审计进入二级页面。
- 反馈默认显示未处理项，支持搜索和负责人筛选；备注与状态操作固定在卡片底部。
- 恢复备份前先生成安全备份，再在隔离数据库预检；显示影响范围和恢复点。
- ECS 运维手册作为唯一部署说明；历史个人电脑部署不再放在主架构文档中。
- 每次发布记录版本、备份、测试数量、健康检查和回滚状态，不在 README 手工维护易过期数字。

## P2：内容精修

- 先处理旧版简历题库，再处理 360 专项和 Java 高频题。
- 首屏短答控制在 40–120 字；超过 160 字拆成“结论 + 展开”。
- 每题只补真正有帮助的一个最小示例或边界，不为了指标强行添加代码和图片。
- 来源定期抽查可访问性，保留 `verifiedAt`；来源失效时进入编辑队列。
- 复核 376 道超长正文，拆成列表、步骤、表格或折叠段落。
